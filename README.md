# BadNotes

굿노트너무비싸고  
아이패드너무구리고  
나는거지다  
그래서만들었다  
앱도 거지같다

---

- iPad용 PDF 필기 앱 (SwiftUI + PDFKit + PencilKit), iPadOS 26 이상 (Liquid Glass)
- 첫 화면은 **서재**: 노트북·PDF를 카드로 고름. [+ 신규]로 노트북 만들기 / PDF 불러오기 / 폴더
- 노트북도 PDF. 가져온 PDF는 앱 폴더로 복사하고, **필기는 그 PDF 안에 저장** → 파일 앱·미리보기·다른 PDF 앱에서도 필기가 보임
- 파일 앱 › 나의 iPad › BadNotes 에 PDF가 그대로 보임
- 오류 나면 빨간 배너 + 로그 창
- 스크롤하면 도구 막대 숨김, 아래 제목 캡슐 누르면 페이지 이동
- 새 버전을 처음 열면 이번 업데이트가 표시됨. 설정 › 정보 › 변경 기록에서 이전 기록을 볼 수 있고, 업데이트 안내 자동 표시를 끌 수 있음

## 필기 방식 (설정에서 고름)
- **BadNotes 필기 도구 (기본, `Editor/Direct/`)**: PDFView 대신 직접 만든 보기 화면
  - 페이지마다 PDF 타일 + 요소 + 필기 타일(CATiledLayer). 확대 배율에 맞춰 조각마다 다시 그려서 아무리 확대해도 선명
  - 지금 긋는 획은 화면 좌표 임시 레이어에, 펜을 떼면 페이지 필기에 넣고 바뀐 영역만 다시 그림
  - 화면 필기와 PDF에 넣는 모양이 같은 렌더러(`Storage/InkRenderer.swift`) → 보이는 그대로 다른 앱에서도 보임
  - 넓은 창에서는 유리 도구 막대가 한 줄에 놓이고, 좁은 창에서는 도구 옵션이 아래 줄로 내려감
    - [‹ 서재 · # 페이지 이동] [올가미 · 펜 · 형광펜 · 지우개 | 텍스트 · 메모지 · 이미지] [페이지 추가 · ⋯]
    - [실행 취소 · 다시 실행]과 선택한 도구의 설정
      - 펜: 펜 종류 ⌄ (볼펜·만년필·붓펜·연필·**Liquid Glass 펜** + 유리 진하기 %) | 굵기 3칸(실제 굵기 선) | 색 3칸 + (+)
        - 볼펜은 균일한 원형 펜촉, 만년필은 방향에 따라 선폭이 달라지는 납작한 펜촉. 붓펜은 필압과 속도에 따라 굵기가 바뀌고 획 끝이 가늘어짐
        - 연필은 획을 따라 흑연 입자를 찍음. 필압으로 농도를 조절하고 펜슬을 눕혀 넓게 칠할 수 있음
      - 형광펜: 곧게 긋기 | 굵기 | 색 / 지우개: 부분·획 | 크기 | 형광펜만
      - 텍스트: 글자 색 | 크기 ⌄ | 글꼴 ⌄ | 굵게 | **유리 글자** (+ 진하기 %) | 정렬 | 바탕 **없음 · 색 · Liquid Glass** (+ 맑게)
      - 메모지: 색 10가지 | **Liquid Glass** 켜기(끄면 종이 메모지) (+ 맑게)
      - 이미지: 사진 보관함 · 파일 (페이지를 누르면 그 자리에)
    - 고른 굵기·색을 한 번 더 누르면 슬라이더·색 고르기 (펜 0.4~16pt, 형광펜 4~48pt, 지우개 4~120pt)
  - 지우개는 막대에 바로 보임: **부분** / **획** / **형광펜만**(글씨는 두고 형광펜만 지움)
    - 부분 지우개는 획을 다시 만들지 않고 보이는 영역(마스크)에서 지나간 자리만 빼서, 남은 부분 모양이 그대로
    - 닿았는지는 가운데 점이 아니라 실제로 칠한 모양으로 판단 (가운데를 지운 뒤 양옆에 남은 가는 조각도 지워짐)
  - 형광펜: 방향과 상관없이 같은 굵기, 반투명 곱하기(밑의 글자 그대로). 거의 곧게 그으면 곧게, 수평 3° 안이면 수평으로
  - 손가락: 스크롤·확대·요소 고르기 / 펜슬: 필기. 두 손가락 탭 실행 취소, 세 손가락 탭 다시 실행, 펜슬 두 번 탭 지우개
- **Apple 필기 도구 (옵션, `Editor/PencilKit/`)**: Apple 도구 팔레트(펜·마커·연필·만년필·수채화·크레용·지우개·올가미·자) 그대로
  - 스크롤뷰 자체가 PKCanvasView라서 Apple이 확대 배율에 맞춰 필기를 다시 그림 → 확대해도 선명 (예전 레이어 모드는 흐렸음)
  - 페이지(PDF 타일 + 요소)는 캔버스 맨 아래에 깔고 같은 배율로 같이 확대
  - 필기는 페이지를 쌓은 좌표 한 장으로 합쳐서 캔버스에 넣고, 바뀌면 획 위치로 페이지를 나눠 저장 → 저장 방식은 기본 모드와 같음
- 두 방식 모두 같은 데이터(PKDrawing). 잉크 굵기는 PencilKit 렌더러로 직접 재서 맞춰서 어느 쪽에서 봐도 같은 굵기
- BadNotes 도구로 그은 획은 씨앗값에 펜 종류를 기록함. 표시 없는 획(Apple 도구로 그은 것·예전 획)은
  BadNotes 도구 모드에서도 Apple 렌더러(PKDrawing.image)로 타일을 그려서 Apple 도구 모드와 똑같이 보임
  (마커·연필·수채화·크레용 질감 그대로). 다른 앱용 PDF 모양은 여전히 비슷하게 그린 벡터
- 참고: 저장했다 열면 PencilKit이 볼펜 잉크(monoline)를 펜(pen)으로 바꿔 놓음. BadNotes는 둘을 똑같이 그려서 영향 없음

## 텍스트 상자 · 유리 메모지 · 사진 (`Editor/Elements/`, `Storage/PageElement.swift`)
- 텍스트·메모지·이미지 도구를 고르고 페이지를 누르면 그 자리에 놓임. 유리로 할지는 그 도구 막대에서 바로 고름
- 상자를 고치는 중에 막대에서 글꼴·크기·색·바탕을 바꾸면 그 상자에 바로 적용 (상자를 고치기 시작하면 막대가 그 상자 모양을 보여 줌)
  - 입력 중에 다른 데를 누르면 입력만 끝남 (그 탭으로 새 상자가 또 생기지 않음)
  - 글꼴: 기본·둥근·명조·고정폭 + 기기에 있는 글꼴(나눔손글씨 등)
- 유리(유리 텍스트 상자·메모지)는 메뉴 › 유리에서 뿌옇게/맑게, 색 진하기(없음~아주 진하게), 유리 색
- 손가락으로 누르면 고르기 → 메뉴(글자 고치기, 바탕, 메모지 색, 글자 크기·굵게·정렬·펜 색으로, 복제, 맨 앞으로, 삭제).
  고른 걸 다시 누르면 글자 고치기, 끌면 옮기기, 오른쪽 아래 손잡이로 크기 (사진은 비율 유지, 글상자는 줄바꿈 다시)
- 유리 바탕·메모지는 진짜 Liquid Glass(UIGlassEffect). 글자·사진·색 바탕은 타일로 그려서 확대해도 선명
- 쌓는 순서: PDF → 요소 → 필기 (필기가 늘 위). 실행 취소 기록은 필기와 같이 씀
- PDF 저장: 페이지마다 Stamp 주석 하나 (`/BNElements` JSON, `/BNImages` 사진 원본, `/BNElementMeta` 좌표계).
  다른 앱용 모양도 그려 넣음(유리는 반투명 판으로 비슷하게). 필기 주석보다 앞에 둬서 다른 앱에서도 필기가 위에 보임
- 사진은 긴 변 2400px 안으로 줄여서 JPEG(투명하면 PNG)로 넣음. 같은 사진은 한 번만 들어감 (내용 해시)

## Liquid Glass 펜 · 유리 글자 (`Storage/GlassInk.swift`)
- 화면에서는 펜 획과 글리프의 윤곽에 SwiftUI의 `glassEffect(_:in:)`를 적용한다. 같은 페이지의 유리펜 획은 `GlassEffectContainer`에서 함께 그린다. [Apple 공식 문서](https://developer.apple.com/documentation/swiftui/applying-liquid-glass-to-custom-views)
- 부분 지우개는 한 번에 들어온 입력 점들을 연결해 획의 마스크를 갱신한다. 획의 원래 윤곽과 필압을 보존하고 지운 자리에 종이와 사진이 드러난다. [iPad 시뮬레이터에서 지우기 전과 다시 열었을 때 비교](docs/screenshots/liquid-glass-eraser.png)
- PDF 파일(다른 앱용 모양)에는 진짜 유리를 넣을 수 없어서 비슷한 그림으로 구움: 비치는 색 몸통 + 반사광 + 그늘 + 빛 테두리
- 이게 싫으면 **.badnote** 형식으로 만들면 흉내를 안 구움 (아래 파일 형식)
- 색 = 고른 펜 색 / 글자 색, 진하기 0~100% (0이면 거의 투명한 유리). 막대의 % 칩을 누르면 미리보기 + 슬라이더
- 저장: 유리펜 획은 PKStroke 씨앗값 위쪽에 표시(0x6A55)와 진하기를 넣어 PKDrawing 그대로 PDF에 들어감. 다른 앱에서도 유리 모양으로 보임
- Apple 필기 도구 모드에서는 유리펜 획이 일반 선으로 보임 (Apple 렌더러가 그림)

## 파일 형식: PDF / BadNotes 노트(.badnote)
- 새 노트북 화면의 [형식]에서 고름 (기본값은 설정 › 파일 형식, 화이트보드도 이걸 따름)
- 둘 다 속은 PDF라서 BadNotes에서는 똑같이 열리고 똑같이 진짜 Liquid Glass로 보임
- PDF: 파일 앱·미리보기·다른 앱에서도 열림. 유리(바탕·메모지·유리 글자·유리펜)는 비슷한 그림으로 구워 넣음
- .badnote: BadNotes 전용. 유리를 흉내 내지 않고 데이터만 둠. 서재 카드에 "BadNotes 노트" 표시,
  카드 ⌄ › **PDF로 내보내기**로 다른 앱용 PDF 사본을 만듦 (원본 그대로)
- 서재 카드 표지는 파일에 구운 모양으로 그려서 .badnote는 유리가 카드에 안 보임

## 화이트보드 (서재 [+ 신규] › 화이트보드)

- 오른쪽 아래 미니맵에서 파란 테두리가 현재 화면을 표시한다. 지도를 누르면 해당 위치로 이동한다. 북마크 메뉴에서 현재 위치에 이름을 붙이거나 저장한 위치로 돌아갈 수 있다.
- 작게 시작(3,000×2,200pt)해서, 보는 곳이나 쓴 것이 가장자리 450pt 안으로 오면 그쪽으로 1,600pt씩 늘어남
  (가장 크게 14,400pt, PDF 한 페이지 한계). 왼쪽·위로 늘면 내용 좌표를 그만큼 밀어서 제자리에 보이고 그때 실행 취소 기록은 비움
- 점 무늬 바탕은 화면에만 그림 (멀어지면 간격을 넓힘) → 파일이 가벼움. 필기·텍스트·메모지·사진 다 됨, 페이지 추가·표지는 없음
- 1배에서 시작해 0.12배까지 멀리, 6배까지 가까이. 다시 열면 쓴 곳 가운데로. 서재 카드는 쓴 곳 둘레만
- Apple 필기 도구 모드에서는 판이 늘어나지 않음 (BadNotes 도구 모드에서 늘어남)

## 페이지 보기 (⋯ 메뉴 또는 설정)
- **책처럼 넘기기** (기본): 한 장씩 보이고, 옆으로 끌거나 아래 캡슐 양옆 ‹ › 로 넘김. 확대해서 보는 중에는 끌면 스크롤
  - **종이 말림** (`Editor/PageCurl.swift`, Metal): 끄는 손가락을 종이 끝이 따라오며 원통처럼 말려 넘어감. 모서리를 잡고 비스듬히 끌면 비스듬히 말림
  - 종이는 책등에 붙어 있어서 멀리 끌어도 안 떨어짐. 놓으면 빠르게 쳤거나 3분의 1쯤 넘겼을 때 끝까지, 아니면 제자리로
  - 곡면 빛·들린 종이 그림자·밑 페이지 그늘. 가로 두 쪽이면 뒷면이 다음 왼쪽 페이지라 그대로 반대쪽에 내려앉음
  - 넘기는 종이 사진은 직접 그림 (화면 찍기는 Liquid Glass를 검게 찍어서, 유리는 PDF용 흉내로 대신)
- **가로 화면에서 두 쪽 펼치기** (기본). 크기가 다른 PDF 페이지도 원본 비율을 유지하며 화면 폭을 절반씩 채움. 세로로 긴 페이지의 아래쪽은 위로 밀어 볼 수 있음. 표지는 오른쪽에, 마지막에 홀로 남은 속지는 왼쪽에 놓임
- 배율: 아래 왼쪽 % 칩 (페이지 맞춤 · 125~300% · **확대 고정**). 맞춤 근처에서 놓으면 딱 맞춤으로, 손가락 두 번 톡 = 맞춤 ↔ 2배.
  확대 고정이면 핀치가 꺼지고 넘겨도 같은 배율. 가로로 화면에 다 들어오면 확대 중에도 옆으로 끌어 넘김
- 끄면 예전처럼 세로로 이어서 스크롤. Apple 필기 도구 모드는 두 쪽 펼치기만 됨 (넘기기 애니메이션은 BadNotes 도구 모드)
- 애니메이션: 노트 열기/닫기, 요소 넣기(톡 튀어나옴)/지우기, 선택 테두리, 도구·옵션 전환, 버튼 누름, 쪽수 숫자, 서재 카드

## 서재와 노트북 (`Library/`, `Notebook/`)
- 서재 = Documents 폴더 (파일 앱 › 나의 iPad › BadNotes). 폴더는 진짜 폴더, 문서는 PDF
- 문서·폴더 카드를 꾹 눌러 끌어다 폴더 카드에 놓으면 그 폴더로 옮김
- 사이드바: 문서 · 즐겨찾기. 카드 ⌄ 메뉴: 즐겨찾기, 이름 바꾸기, 옮기기, **표지 바꾸기**, 삭제(앱 안 보관함 `Application Support/BadNotes/Deleted`로)
- 새로운 노트북: 표지 21가지(클래식 8 · 패턴 7 · 그림 6), 종이 5가지(백지·점선지·모눈·줄 좁은/넓은 간격) × 노랑·흰색·검정 × A4/iPad 세로·가로
  - 표지는 전부 벡터(`CoverArt`): 면·선·글자만, 그라데이션 없음 → 아무리 확대해도 선명하고 색 띠가 안 생김
  - 표지 바꾸기: 첫 장을 새 표지로 갈아 끼움. 표지 위 필기·요소는 새 표지로 옮김. 표지가 없던 PDF는 맨 앞에 넣음
  - 종이 정보는 PDF 키워드 `BadNotesPaper=...`, 표지는 `BadNotesCover=...`에 넣어서 파일만 있으면 따라다님
- 서재 카드 표지 = 첫 페이지를 화면 픽셀 그대로 그린 PNG (카드 크기를 키우면 그 크기로 다시 그림)
- 편집기에서 [페이지 추가]: 노트북이면 같은 종이, 그냥 PDF면 마지막 페이지 크기의 흰 종이
- 다시 열면 마지막으로 보던 페이지부터. 새 노트북은 표지 다음 장부터

## 테마 (`Theme/`)
- 바탕: 내 사진(기본 레이어) / 단색 / 그라데이션 → 그 위에 Liquid Glass 한 겹(켜기·재질·색)
- 강조색, 문서 카드(책/유리, 크기), 편집기 배경, 라이트/다크, 기울이면 바탕이 따라 움직임
- 프리셋: 기본, 다크, 종이, 바다, 숲 + 내 테마 저장. 바꾸면 미리보기와 앱 전체에 바로 반영
- 바탕 그림은 보이기만 하고 터치는 안 받음 (꽉 채운 사진이 틀 밖으로 넘쳐 옆 버튼·슬라이더 터치를 먹던 문제 고침)

## 저장 방식 (`BadNotes/Storage/`)
- 페이지마다 Stamp 주석 하나에 필기를 넣음 (요소는 따로 하나, 위 참고)
  - 보이는 모양: 벡터 appearance stream (PDFKit이 저장할 때 `InkAnnotation.draw`로 기록) → 다른 앱용
  - 편집용 원본: `/BNInk`(PKDrawing, LZFSE + base64), `/BNMeta`(형식 버전 + 저장 당시 페이지 좌표계)
  - 다른 앱이 페이지를 돌리거나 잘라도 `/BNMeta`로 필기 위치를 맞춰 줌
- 획·요소가 바뀌면 0.4초 뒤 복구 기록(`Application Support/BadNotes/Journal`, 요소와 사진도), 몇 초 모아서 PDF 저장(백그라운드)
  - PDF 저장: 임시 파일에 쓰고 → 다시 열어 검증 → 원본과 원자적으로 교체. 실패하면 원본 그대로, 복구 기록 유지, 재시도
  - 앱이 죽어도 다음에 열 때 복구 기록에서 되살림
- 문서를 연 뒤 첫 저장 전에 백업(`Application Support/BadNotes/Backups`, 문서당 최근 5개)
- 옛 방식(`<파일이름>.notes/pageN.drawing`)은 앱 시작할 때 PDF 안으로 자동으로 옮김. 옮기기 전 PDF는 영구 백업, 옛 폴더는 `Migrated/`로 보관

## 디버그 빌드 점검용 실행 인자
- `-BNSelfTest`로 저장·필기 엔진, 지우개, 요소, 혼합 크기 PDF의 두 쪽 배치, 표지 넘김과 취소, 종이 말림, PencilKit 호환성을 점검함 (`xcrun simctl launch --console-pty booted com.geonu9xpy.BadNotes -BNSelfTest`)
- `-BNCurlDemo`: 시연 문서에서 종이를 반쯤 넘긴 채로 멈춰 보여 줌 (화면 찍기용)
- `-BNInkDemo`: 직접 필기 모드에서 펜·형광펜·지우개·실행 취소·올가미·확대를 차례로 시연
- `-BNFingerDraw`: 손가락(시뮬레이터 마우스)으로 필기 / `-BNAppleTools`: Apple 필기 도구 모드로 열기
- `-BNPreset <번호>`, `-BNShowTheme`, `-BNShowSettings`: 테마 프리셋 적용, 테마·설정 화면 바로 열기
- `-BNShowNewNotebook`: 새로운 노트북 화면 바로 열기 / `-BNMakeNotebook`: 시연 노트북을 만들어서 열기
- `-BNGlassDemo`: 유리 글자·유리펜 시연 노트(.badnote)를 만들어서 열기
- `-BNPhotoTest`: 점검용 바탕 사진 넣기 / `-BNOpenLast`: 마지막 문서 열기
- 실제 기기에서는 `xcrun devicectl device process launch --device <기기> com.geonu9xpy.BadNotes -- -BNSelfTest` (인자 앞에 `--`, 기기 잠금 풀려 있어야 함)

## 알려진 문제
- 다른 앱에서 보이는 필기 모양은 근사치 (연필 질감은 투명도로, 반투명 잉크는 획마다 평균 굵기로)
- 다른 앱에서 보이는 유리 바탕·메모지는 반투명 판으로 비슷하게 그린 것 (진짜 유리는 BadNotes 화면에서만)
- Liquid Glass는 뿌옇게 비치는 재질이라 종이의 가는 줄은 유리 너머로 잘 안 보임
- Apple 필기 도구 모드에서 글상자를 고치는 중에는 손가락으로 커서를 옮길 수 없음 (Apple 캔버스가 위에 있어서). 키보드 화살표는 됨
- 암호 걸린 PDF는 아직 못 엶

## 빌드
Xcode로 `BadNotes.xcodeproj` 열고 Signing에서 본인 팀 골라서 실행.
